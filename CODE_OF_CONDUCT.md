# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
(© Contributor Covenant, licensed CC BY 4.0). The short version:

- Be respectful. Criticize code, docs and ideas, not people.
- No harassment, discrimination, personal attacks, or publishing someone's private information.
- Assume good faith, say what you need plainly, and accept that maintainers may edit,
  close or remove contributions that do not follow these rules.

## Reporting and enforcement

Use GitHub's own tools: report the comment, issue or user through the **Report** menu,
which reaches the maintainer privately. For anything that also puts people or their data at
risk, use the private route in [SECURITY.md](SECURITY.md).

The maintainer decides the response, from a private warning to a temporary or permanent
block, following the enforcement guidelines in the Covenant text linked above.
